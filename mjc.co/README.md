# mjc site

Plain HTML, CSS and JS. No build step. Drop everything in your repo root (Vercel serves it as-is).

Pages: index, work, emporium, mangosalad, vr-experience, services, about, contact.

Look: white page, serif type (Instrument Serif, Newsreader, Fraunces via Google Fonts, with Georgia fallback).
Each project is an "island" with its own theme, defined by the .t-emp, .t-mango, .t-vr and .t-paper blocks in assets/css/mjc.css.

Images reuse your existing files under assets/images/ (EMP, SPF, VRXP, Art, Design, Mangosalad).
If a file is missing, its tile hides itself instead of showing a broken icon.

Replaces: styles.css, desktop/tablet/phone.styles.css and script.js.
Not carried over: Good Dirt Co., Arthouse and Neuroline sections, the personal Instagram link and the Mirror link.
